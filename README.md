# Сайт компании "Бурятзолото"

> Многостраничный веб-сайт компании по добыче золота "Бурятзолото" в Республике Бурятия

## Описание проекта

Расчетно-графическое задание по веб-разработке. Сайт компании "Бурятзолото" ПАО (BRZL) включает 5 HTML-страниц с использованием современного HTML5, CSS3 и JavaScript. Сайт отражает основные характеристики официального веб-сайта компании с соответствующим дизайном.

### Вариант задания:
- **Компания**: Бурятзолото ПАО ао (вариант 19)
- **Валюта**: Канадский доллар CAD (вариант 19)
- **Тип меню**: Боковое меню на всю высоту сайта, прокручивающееся вместе со страницей (вариант 3)

## Функциональность

### Страницы сайта:

#### 1. **О компании** (`index.html`)
- Информация о компании и её направлениях деятельности
- История создания и развития
- Сведения о руководстве
- Достижения и награды
- Минимум 3 экрана контента
- Оформление текста: **жирный**, *курсив*, <u>подчёркивание</u>
- Внутренние ссылки на другие страницы
- Заголовки и структурированный контент

#### 2. **Новости** (`news.html`)
- Минимум 10 новостей о компании
- Карточки с датой, заголовком и первыми 2-3 строками текста
- Функция "Показать полностью" для расширения полного текста новости
- Интерактивные кнопки для управления отображением

#### 3. **Курс валют** (`currency.html`)
- Актуальный курс CAD/RUB на текущий день
- Загрузка курса из API ЦБР (https://www.cbr-xml-daily.ru/)
- Калькулятор с двусторонней конвертацией:
  - RUB → CAD
  - CAD → RUB
- Столбчатая диаграмма изменения курса за последний месяц
- Интерактивность: клик по столбцу показывает дату и курс

#### 4. **Контакты** (`contacts.html`)
- Контактные данные (телефоны, адреса)
- Информация о филиалах компании
- Интерактивная карта (Google Maps в виде iframe)
- Режим работы и контактная информация

#### 5. **Видео** (`video.html`)
- Встроенное видео с YouTube (iframe)
- Документальный фильм о добыче золота
- Дополнительная информация о производстве
- Разделы об экологичности и безопасности

### Дизайн
- **Боковое меню** (вариант 3): прокручивается вместе со страницей
- Единая цветовая схема на основе золотого (основной цвет компании)
- Адаптивный дизайн для мобильных устройств
- Навигация между всеми страницами
- Подсвечивание активной страницы в меню
- Кнопка "Наверх" в нижнем правом углу (фиксированная)

## Технологии

- **HTML5** — семантическая разметка страниц
- **CSS3** — современные стили, flex-layout, grid
- **JavaScript (Vanilla)** — интерактивность и функциональность
- **Chart.js** — библиотека для создания диаграмм
- **API ЦБР** — получение актуальных курсов валют
